# AI Workplace Productivity Assistant

## Project Overview

The AI Workplace Productivity Assistant is a modern, AI-powered web application designed to help professionals automate common workplace tasks, improve productivity, and streamline daily workflows.

The platform leverages Artificial Intelligence to assist users with drafting professional emails, summarizing meeting notes, planning tasks, conducting research, and interacting with an AI workplace assistant through a chatbot interface.

This project was developed as part of the AI Skill Accelerator Programme and demonstrates practical AI implementation, prompt engineering, responsive web design, and responsible AI practices.

---

## Features

### Smart Email Generator

Generate professional, context-aware emails tailored to different audiences and communication styles.

**Capabilities:**

* Professional email drafting
* Multiple tone options (Formal, Friendly, Persuasive, Professional)
* Audience-specific content generation
* Editable AI-generated output
* Copy and regenerate functionality

### Meeting Notes Summarizer

Transform lengthy meeting notes into concise and actionable summaries.

**Capabilities:**

* Executive summaries
* Key discussion points
* Action item extraction
* Decision tracking
* Deadline identification

### AI Task Planner

Create structured daily and weekly work plans.

**Capabilities:**

* Task prioritization
* Schedule generation
* Time optimization recommendations
* Productivity-focused planning
* Workload organization

### AI Research Assistant

Quickly analyze and summarize information from articles, reports, and research topics.

**Capabilities:**

* Research summaries
* Key insights extraction
* Recommendations generation
* Simplification of complex information
* Business-focused analysis

### AI Workplace Chat Assistant

An interactive AI chatbot designed to support workplace productivity.

**Capabilities:**

* Workplace-related assistance
* Productivity recommendations
* Information summarization
* Communication support
* Threaded conversation history

### Dashboard

A centralized dashboard providing quick access to all productivity tools.

**Features:**

* Productivity statistics
* Recent activities
* Quick action shortcuts
* Modern SaaS-style interface

### Responsible AI

The application promotes ethical AI usage by including:

* AI-generated content disclaimer
* Human review recommendations
* Transparency notices
* Awareness of AI limitations and potential inaccuracies

## Setup Instructions

### Prerequisites

Ensure the following are installed:

* Node.js (v18 or later)
* npm or yarn
* Git

---

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

Navigate to the project folder:

```bash
cd ai-workplace-productivity-assistant
```

Install dependencies:

```bash
npm install
```

---

### Environment Variables

Create a `.env` file in the project root and add:

```env
VITE_OPENAI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your AI provider API key.

---

### Run the Development Server

```bash
npm run dev
```

The application will start locally and can be accessed at:

```text
http://localhost:5173
```

---

### Build for Production

```bash
npm run build
```

---

### Preview Production Build

```bash
npm run preview
```
